# Lumina Startup Checklist

This is a living checklist for the Lumina founding team. Use this to track the essential tasks required to go from zero
to a fully operational, investor-ready startup.

---


## 🏗️ Foundation

### Legal & Company

- [ ] Incorporate the company (Delaware C-Corp recommended for US investors)
- [ ] Obtain EIN (Employer Identification Number)
- [ ] Open a business bank account
- [ ] Set up accounting software (QuickBooks, Wave, or Bench)
- [ ] Draft founder vesting agreements (4-year, 1-year cliff)
- [ ] File IP assignment agreements (all code/IP belongs to the company)
- [ ] Register trademark for "Lumina" in key markets
- [ ] Obtain D&O insurance
- [ ] Draft Terms of Service and Privacy Policy
- [ ] Ensure GDPR and CCPA compliance documentation

### Domain & Infrastructure

- [x] Register primary domain (luminohq.com)
- [ ] Set up DNS with Cloudflare
- [ ] Configure email domain (Google Workspace recommended)
- [ ] Set up Cloudflare for DDoS protection and CDN
- [ ] Configure Vercel for web app hosting
- [ ] Set up Railway or Fly.io for backend services
- [ ] Provision managed PostgreSQL (Neon, Supabase, or RDS)
- [ ] Provision managed Redis (Upstash or Redis Cloud)
- [ ] Set up Cloudflare R2 or AWS S3 for file storage
- [ ] Configure Sentry for error tracking
- [ ] Set up PostHog for product analytics
- [ ] Configure Resend for transactional email

## 🛠️ Product

### MVP Features

- [x] User authentication (email/password + OAuth)
- [x] Dashboard with basic chart types
- [x] PostgreSQL data connector
- [x] Real-time chart updates
- [x] Organization and team management
- [ ] AI natural language querying (NLQ)
- [ ] Stripe billing integration
- [ ] Self-serve onboarding flow
- [ ] In-app help and documentation
- [ ] Mobile-responsive dashboard views

### Quality & Reliability

- [ ] Set up CI/CD pipeline (GitHub Actions)
- [ ] Achieve >80% test coverage on core packages
- [ ] Load test to 10,000 concurrent users
- [ ] Set up uptime monitoring (BetterUptime or Pingdom)
- [ ] Configure automated database backups (daily, 30-day retention)
- [ ] Disaster recovery runbook documented and tested
- [ ] Set up on-call rotation with PagerDuty

## 💼 Business

### Go-To-Market

- [ ] Define ICP (Ideal Customer Profile)
- [ ] Build first 100 beta user waitlist
- [ ] Launch on Product Hunt
- [ ] Submit to Hacker News "Show HN"
- [ ] Set up Intercom for customer support
- [ ] Write first 5 SEO blog posts
- [ ] Create demo video (< 3 minutes)
- [ ] Set up affiliate/referral program

### Sales & Revenue

- [ ] Define pricing tiers (Free, Growth, Enterprise)
- [ ] Integrate Stripe for subscription billing
- [ ] Create sales deck (10-slide deck for investor meetings)
- [ ] Set up CRM (HubSpot Free or Attio)
- [ ] Close first 3 paying customers
- [ ] Reach $10k MRR

### Investors & Fundraising

- [ ] Prepare pitch deck
- [ ] Create financial model (3-year projection)
- [ ] Draft data room materials
- [ ] Begin angel/pre-seed conversations
- [ ] Target 12 months runway from first funding
